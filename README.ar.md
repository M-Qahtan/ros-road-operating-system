# ROS — نظام تشغيل الطريق

ROS ليس تطبيق بلاغات، بل طبقة تشغيل ذكية تحول الإشارات المتفرقة إلى **حدث طريق موحد RoadEvent**، وتضع سلامة الإنسان أولًا، وتنسق الاستجابة، وتحفظ الأدلة، وتتابع الطريق حتى استعادة الحركة.

## هدف تجربة الرياض

إثبات قدرة النظام على إدارة دورة الحادث كاملة: الاكتشاف، التحقق، التواصل الآمن، التصعيد البشري، التنسيق التشغيلي، إدارة الحركة، حفظ الأدلة، الإخلاء، الاستعادة، ثم الإغلاق المدقق.

## المبادئ الثابتة

- الإنسان قبل انسيابية المرور.
- الإشارة ليست حادثًا مؤكدًا.
- القواعد القابلة للتفسير قبل نماذج الذكاء الاصطناعي غير المتحققة.
- مراجعة بشرية إلزامية للقرارات الطبية والقانونية والحكومية وعالية الخطورة.
- كل قرار حساس وانتقال حالة مسجل وقابل للتدقيق.
- نبدأ بـModular Monolith، ولا نفصل الخدمات إلا عندما تثبت الحاجة التشغيلية.
