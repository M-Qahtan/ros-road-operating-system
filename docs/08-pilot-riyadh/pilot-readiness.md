# Riyadh Pilot Readiness

The pilot is Go only when P0 workflows are demonstrated end to end, critical security findings are closed, backups restore successfully, audit reconstruction is complete, operators pass simulations and all agency interactions are clearly marked as simulated.

## Success measures

Time to detect, time to RoadEvent, time to safety contact, no-response escalation time, merge precision, critical miss rate, notification delivery, operator acknowledgement and time to road recovery.
