# AI and Data Architecture

## MVP

- deterministic signal quality rules;
- geospatial and temporal correlation;
- explainable severity scoring;
- no-response and safety escalation rules;
- optional language-model assistance for extraction and summarization only.

## Later models

Incident detection, learned correlation, severity prediction, computer vision and predictive risk require labelled, representative and independently validated data.

## Validation rule

No accuracy claim is permitted without a versioned dataset, holdout evaluation, precision/recall, critical-miss analysis, calibration, subgroup bias analysis and field validation.

## Governance

Every model requires a model card, dataset card, approved use cases, prohibited uses, rollback process and human override.
