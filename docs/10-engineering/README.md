# Engineering controls

This directory contains operational engineering controls that apply across the ROS repository.

- `main-branch-protection.md`: mandatory merge gates and emergency bypass rules for `main`.
- `ci-required-checks-verification.md`: evidence checklist for issue #19.
- `ci-evidence-schema.json`: versioned schema for per-job CI evidence manifests.
- `required-checks.txt`: canonical required check names used by the branch ruleset.
