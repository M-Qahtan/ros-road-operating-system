# Program Risk Register

| Risk | Level | Control |
|---|---:|---|
| Incorrect event merge | High | road segment + direction + confidence + human review |
| Missed critical incident | Critical | conservative thresholds + multi-source detection + escalation |
| Sensitive data exposure | Critical | minimization + encryption + RBAC + immutable audit |
| Scope expansion | High | MVP freeze and P0 gates |
| External agency dependency | High | adapters and operational simulation |
| Unvalidated AI claims | High | shadow mode and independent validation before claims |
